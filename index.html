Features

Everything your media workflow needs

Four focused tools, one desktop app. Built for people who want control over their local media.

Downloader

Inspect supported media URLs, choose source quality and output formats, and queue downloads with yt-dlp.

  • Quality & format selection
  • Background download queue
  • Browser cookie profiles

Media Converter

Convert local audio and video files with FFmpeg without leaving the app.

  • Audio & video conversion
  • FFmpeg / FFprobe powered
  • Reusable download presets

Music Hub

Search music catalogs, resolve public Spotify metadata, and fetch matching audio for your library.

  • Track, album & playlist metadata
  • Local audio library
  • Custom playlists

Queue & Settings

Monitor background tasks and configure output folders, connections, cookies, and presets.

  • Live task monitoring
  • Output folder control
  • Connection & cookie settings

Install

Get Universal Media Studio running

Clone the repository and launch the app with a single script, or set it up manually.

Quick start with the launcher

  1. Clone the repository and open its folder.
  2. Run run_windows.bat — it creates .venv, installs requirements, and starts the app.

Or set up manually

PowerShell / Command Prompt
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python app.py

Set up a virtual environment

Run run_linux.sh for the development launcher, or follow the manual steps below.

Terminal

Terminal
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python app.py

Build a standalone Windows executable

The included builder installs dependencies and PyInstaller in .venv, bundles the QML interface, and produces an onedir build for faster startup and easy troubleshooting.

Command Prompt

Command Prompt
builder.bat

# Output:
# dist/Universal Media Studio/Universal Media Studio.exe

Distribute the entire output folder, not just the executable. FFmpeg can be bundled from project-local locations or installed on your system PATH.

Troubleshooting

FFmpeg not detected

Add its bin folder to PATH, or set the FFmpeg and FFprobe paths in Settings.

yt-dlp errors

Upgrade yt-dlp — extractors change often. Some sites need a supported browser cookie profile.

Qt / QML errors

Build with the same Python environment that has PySide6 installed and keep ums/qml intact.

Use it responsibly

Download only media you own or are authorized to save. Spotify links are used for public metadata resolution only; this application does not use Spotify's authenticated Web API.
