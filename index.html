Features

Everything your media workflow needs

Four focused areas in one local desktop app. Every download and conversion runs on your machine.

Downloader

Analyze a URL and pick exactly the source you want with yt-dlp.

  • List formats yt-dlp exposes for a URL
  • Best video + audio, audio-only, or capped resolution
  • Batch URLs, one per line, and playlists
  • Subtitles, auto-captions, and thumbnails
  • Retries, proxy modes, and browser cookie reuse

FFmpeg Conversion

Convert or remux local files and downloads with FFmpeg, from quick copies to full encoding control.

  • Copy-remux without re-encoding
  • H.264, HEVC, AV1, VP9, and more
  • CRF, CBR, and VBR rate control
  • FPS, resolution, 10-bit, and color options
  • NVENC, QSV, or AMF where your build supports them

Queue & Presets

Sequential background work with full visibility, plus reusable profiles.

  • Cancel, retry, and reorder queued tasks
  • Per-task logs and session history
  • Custom presets saved locally
  • Smallest File, Mobile, Archive, Audio Only and more
  • Output folder and tool paths in Settings

Music Workspace

Discover music, match it to audio, and keep a tagged local library with playlists.

  • Search Deezer, Apple Music, YouTube, SoundCloud
  • Public Spotify metadata, no API keys needed
  • Lyrics lookup via LRCLIB
  • Library with artwork, tags, and favorites
  • Local playlists with M3U / M3U8 import & export

Built-in profiles

Start from a profile, then open advanced controls only when you need them.

Get the app

How it works

From link to file in four steps

01

Analyze the URL

Open the Downloader, paste one or more links, and click Analyze to see the formats yt-dlp can access.

02

Choose quality & format

Select a source quality and output container, or pick a preset. "Original" keeps the file as downloaded.

03

Queue the task

Open the Queue to watch progress and logs, cancel or retry tasks, and reorder what runs next.

Have local files? Use the Converter to queue one or more FFmpeg jobs.

Install

Get Universal Media Studio running

Clone the repository and start the app with the launcher for your platform, or set it up manually.

Get the code

Clone the repository, or download the main branch as a ZIP and extract it.

Open repository Download ZIP

Quick start with the launcher

  1. Install Python 3.10+ from python.org and enable Add Python to PATH.
  2. Install FFmpeg from a trusted distribution and add its bin folder to PATH, or set the executable paths in the app's Settings.
  3. Double-click run_windows.bat. The first launch creates .venv, installs PySide6 and yt-dlp, then opens the app.

Or set up manually

PowerShell / Command Prompt
git clone https://github.com/mhhanzala12/UMS.git
cd UMS
py -3 -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python app.py

Run on Linux or macOS

Install Python 3.10+ and FFmpeg first, plus the Qt runtime libraries on many Linux distributions. Then run the launcher, or follow the manual steps.

Launcher

Terminal
python3 -m venv .venv

The original Widgets UI is still available as a fallback with python legacy_app.py (Windows: run_legacy_windows.bat).

Build a Windows app folder

Run build_windows_exe.bat to create an optional Windows app folder with PyInstaller. The script includes the QML directory as application data.

YouTube support

  • Install Deno (or another yt-dlp-supported JavaScript runtime) and put it on PATH.
  • Keep yt-dlp current: python -m pip install -U "yt-dlp[default]"
  • Connection settings support system proxy, manual HTTP(S) proxy, or direct mode.

Troubleshooting

yt-dlp missing or formats unavailable

Upgrade yt-dlp with python -m pip install -U "yt-dlp[default]", install Deno, then restart the app.

FFmpeg missing

Install FFmpeg, restart the app, and check Settings → Detected tools.

Separate streams fail to merge

Install FFmpeg and make sure ffmpeg is on PATH.

Encoder not found

Your FFmpeg build may not include that encoder. Choose another codec or install a build that has it.

Unsupported or protected URL

Try a source with accessible, non-DRM media, and read the yt-dlp error in the Queue activity log.

Limitations & privacy

Clear about what it does and doesn't do

Known limitations

  • A desktop app, not a browser extension. It does not read the tab you have open.
  • Does not bypass DRM, encryption, subscriptions, authentication, geo restrictions, or site access controls.
  • Site support depends on yt-dlp and the site. No universal support is promised.
  • Queue tasks run one at a time. Pause and resume are not exposed.
  • No two-pass encoding, exact file-size targeting, or raw FFmpeg argument entry.
  • Encoder and hardware acceleration depend on your FFmpeg build, GPU, and drivers.

Privacy & safety

  • URL inspection and processing run locally through yt-dlp and FFmpeg.
  • No analytics, telemetry, ad network, cloud conversion API, or media proxy.
  • Settings are stored in ~/.universal_media_studio/settings.json.
  • Media is saved only to the output folder you choose.
  • No FFmpeg binaries are bundled or downloaded silently.

Use it responsibly

Download only media you own or are authorized to save. Spotify links are used for public metadata resolution only; this application does not use Spotify's authenticated Web API or any Spotify credentials.
